# THE BEYBÛN HOTEL — Website

Professional multi-page hotel website (HTML, CSS, JavaScript).

## Open locally

Double-click `index.html`, or from this folder run:

```bash
npx --yes serve .
```

Then open the URL shown in the terminal (usually `http://localhost:3000`).

## Pages

- `index.html` — Home
- `rooms.html` — All rooms
- `room-standard.html` — Standard Room
- `room-triple.html` — Triple Room
- `room-jacuzzi.html` — Jacuzzi Room
- `about.html` — About
- `gallery.html` — Gallery
- `contact.html` — Contact & booking

## Languages

Top-right switcher: **EN** (default), **IT**, **ES**, **FA** (Persian, right-to-left).  
Language choice is saved in the browser.
